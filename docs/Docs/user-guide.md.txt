# User Guide: Noodles Crypto Dashboards

## Overview

This guide explains how to access and use the Noodles currency analytics
dashboards for market insights and decision-making.

## Accessing Dashboards

**Option 1: Power BI Service (Recommended)**

1. Visit: https://app.powerbi.com
2. Sign in with your organizational account
3. Navigate to "Noodles Analytics" workspace
4. Open "Executive Dashboard" report

**Option 2: Power BI Desktop**

1. Download .pbix file from shared folder
2. Open with Power BI Desktop
3. Click "Refresh" to load latest data

## Available Dashboards

### 1. Executive Dashboard

**Purpose**: High-level market overview for executives

**Key Metrics**:

- Total Market Capitalization
- Average Price Across Currencies
- Trading Volume (24h)
- Number of Active Currencies

**How to Use**:

- Use date slicer (top-right) to select time period
- Click any visual to filter others (cross-filtering)
- Hover over data points for detailed tooltips

### 2. Top Performers Report

**Purpose**: Identify market winners and losers

**Features**:

- Top Gainers table (sorted by % change)
- Top Losers table
- Volume leaders
- Price trend indicators

**How to Use**:

- Adjust "Top N" parameter (default: 10)
- Right-click any currency for drill-through details
- Export data using "..." menu

### 3. Currency Deep Dive

**Purpose**: Detailed analysis of individual currencies

**Features**:

- Price trends with moving averages
- Volume analysis
- Social engagement metrics
- Historical comparisons

**How to Use**:

- Access via drill-through from other reports
- Or use currency selector dropdown
- Compare multiple currencies using Ctrl+Click

## Common Tasks

### Filter by Date Range

1. Locate date slicer (usually top-right)
2. Click calendar icon
3. Select start and end dates
4. Or use relative date: "Last 30 days", "YTD"

### Export Data

1. Click "..." menu on any visual
2. Select "Export data"
3. Choose format: .xlsx or .json
4. Open in Excel for further analysis

### Print/Export Report

1. File → Export → PDF
2. Select pages to export
3. Adjust page size if needed
4. Save to desired location

### Share with Colleagues

1. Click "Share" button (top-right)
2. Enter email addresses
3. Set permissions (can view/can edit)
4. Add message and send

## Understanding Key Metrics

| Metric         | What It Means            | How to Use         |
| -------------- | ------------------------ | ------------------ |
| Market Cap     | Total value of all coins | Gauge market size  |
| 24h Volume     | Trading activity         | Identify liquidity |
| Price Change % | Price movement           | Spot trends        |
| Moving Average | Smoothed trend line      | Identify direction |
| Volatility     | Price stability          | Assess risk        |

## Tips & Best Practices

✅ **DO**:

- Refresh data before important meetings
- Use filters to focus on relevant data
- Export data for offline analysis
- Share insights with team

❌ **DON'T**:

- Make decisions on stale data (check refresh time)
- Ignore data quality warnings
- Share sensitive reports externally

## FAQ

**Q: How often is data updated?**  
A: Daily at 6:00 AM. Check "Last Refresh" timestamp in report header.

**Q: Why do I see different numbers than yesterday?**  
A: Data is refreshed daily. Historical data may also be revised.

**Q: Can I create my own reports?**  
A: Yes, if you have Power BI Pro license. Contact IT for access.

**Q: Who do I contact for questions?**  
A: Email data-analytics@noodles.com or Slack #data-help
